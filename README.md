# Ma Cocotte

Ma Cocotte est un site de recettes de plats mijotés réalisé en équipe à l’ESGI en octobre 2026. Le site propose des fiches avec un carrousel photo, les ingrédients, les ustensiles et les étapes de préparation.

## Ma contribution

J’ai développé les trois fiches de recettes du site :

- [Blanquette de veau](recette_blanquette.php)
- [Bœuf bourguignon](recette_boeuf.php)
- [Pot-au-feu](recette_pot-au-feu.php)

Les fiches utilisent Bootstrap pour le carrousel et des inclusions PHP pour réutiliser l’en-tête et le pied de page communs au site.

## Technologies

PHP, HTML, CSS et Bootstrap. Le projet a été testé en local avec MAMP.

## Lancer le site en local

1. Télécharge le dépôt et place le dossier du projet dans le répertoire `htdocs` de MAMP.
2. Démarre les serveurs depuis MAMP.
3. Ouvre `index.php` depuis l’adresse locale indiquée par MAMP.
